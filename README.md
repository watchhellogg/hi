# 北海道支部会 学会知識ベース（Obsidian）

日本脳神経外科学会 北海道支部会の **動画・発表スライド写真** から、
臨床と研究に使える「コンテキスト」を集めて Obsidian に蓄積するための道具一式。

> [!important] 取り扱い
> - 学会の動画・スライドは演者の著作物、かつ患者画像を含む可能性がある → **個人学習用のみ**。
>   `.gitignore` で画像・動画はリポジトリに入らないようにしてある（共有・SNS掲載はしない）。
> - 学会発表は査読前の情報。ノートの `確認状態` を使い、**論文・ガイドラインで裏取りしたものだけを臨床判断に使う**。

---

## 全体の流れ（Step by step）

```
[動画]  ──extract_slides.py──▶ スライド静止画 + index.md ─┐
   └──transcribe.py(任意)───▶ 文字起こし(タイムスタンプ付) ─┼─▶ Claude が演題ノートを下書き ─▶ 自分で「解釈」「Pearl」を書く
[写真]  ──organize_photos.py─▶ 演題ごとのフォルダ + index.md ─┘                                  ▼
                                                                         疾患ハブ・ダッシュボードに自動集計(Dataview)
```

### Step 0. 準備（初回のみ・自分の PC で）
```bash
brew install ffmpeg          # Mac。Windows は winget install ffmpeg
```
```bash
pip install pillow pillow-heif
```
```bash
pip install faster-whisper   # 文字起こしをする場合のみ
```
Obsidian で `vault/` フォルダを「保管庫として開く」→ コミュニティプラグイン **Dataview** と、
コアプラグイン **テンプレート**（テンプレートフォルダ = `90_Templates`）を有効化。

### Step 1. 動画 → スライド抽出
```bash
python scripts/extract_slides.py 動画/演題03.mp4 out/第XX回/演題03
```
- 2 秒ごとにフレームを見て、**変化した画素が 0.2% 以上** のときだけ保存（箇条書き 1 行の追加も拾い、圧縮ノイズは無視）。
- 演者カメラの小窓がある動画は `--crop 0,0,0.75,1`（左 75% だけで判定）のように指定。
- 拾いすぎ → `--min-change 0.5`、取りこぼし → `--min-change 0.1`。

### Step 2.（任意）文字起こし
```bash
python scripts/transcribe.py 動画/演題03.mp4 out/第XX回/演題03/transcript.md --model medium
```
口頭説明と **質疑応答** はスライドに無い情報で、コンテキストとして価値が高い。
誤変換が多い用語は `transcribe.py` の `NEURO_PROMPT` に追記すると改善する。

### Step 3. スライド写真 → 演題ごとに束ねる
```bash
python scripts/organize_photos.py ~/Pictures/支部会写真 out/第XX回/photos --gap 6
```
撮影時刻が 6 分以上空いたら別演題とみなす。連写の重複は自動で間引く。元の写真は動かさない（コピーする）。
**プログラム（演題一覧）のページも撮っておく**と、グループと演題名の対応付けが楽になる。

### Step 4. Obsidian に取り込む
1. `out/第XX回/` を `vault/10_学会/北海道支部会/第XX回/` にコピー
2. `学会ハブ` テンプレートで `第XX回.md` を作成
3. 各演題フォルダで `演題ノート` テンプレートからノートを作成

### Step 5. Claude に下書きさせる → 自分で仕上げる
スライド画像（と transcript.md）を Claude に渡して、次のように頼む：

> この演題のスライドと文字起こしから、`演題ノート` テンプレートの 1〜6 を埋めて。
> 数値はスライドに書いてあるものだけ使い、読めない箇所は「要確認」と書くこと。
> 7（自分の解釈）は、関連するガイドライン・主要 RCT を挙げて一致/矛盾を指摘する形で下書きして。

**7. 自分の解釈 / 8. 臨床 Pearl は必ず自分の言葉で書き直す** — ここが学習効果の本体。

### Step 6. 横につなぐ
- `疾患:` に `[[破裂脳動脈瘤]]` のように書くと、`20_疾患/` の疾患ハブに演題が自動で集まる
- 「これは研究になりそう」→ `研究アイデア` テンプレートで `40_研究アイデア/` に切り出す
- `00_ダッシュボード.md` で「未確認の演題」「★3 の Pearl」を一覧

## フォルダ構成
```
vault/
├── 00_ダッシュボード.md
├── 00_Inbox/                 未整理のメモ
├── 10_学会/北海道支部会/第XX回/  学会ハブ + 演題ノート + スライド
├── 20_疾患/                  疾患ハブ（学会知見が自動集計される）
├── 30_手技・デバイス/
├── 40_研究アイデア/
├── 90_Templates/             演題ノート / 学会ハブ / 疾患ハブ / 研究アイデア
└── 99_Attachments/
scripts/
├── extract_slides.py         動画 → スライド静止画
├── transcribe.py             動画 → 文字起こし（faster-whisper）
└── organize_photos.py        写真 → 演題ごとにグループ化
```
