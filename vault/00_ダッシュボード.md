# 学会知識ダッシュボード

> Community plugin **Dataview** が必要です（設定 → コミュニティプラグイン → Dataview）。

## 未確認の演題（数値・主張を論文で裏取りする）
```dataview
TABLE 回, 演題名, 疾患, 臨床有用度
FROM "10_学会"
WHERE type = "演題" AND 確認状態 = "未確認"
SORT 臨床有用度 DESC
```

## 臨床有用度 ★3
```dataview
LIST 演題名
FROM "10_学会"
WHERE type = "演題" AND 臨床有用度 = "★3"
```

## 分野別の演題数
```dataview
TABLE length(rows) AS 件数
FROM "10_学会"
WHERE type = "演題"
GROUP BY 分野
```

## 研究アイデア
```dataview
TABLE 状態, 着想元
FROM "40_研究アイデア"
WHERE type = "研究アイデア"
SORT 状態 ASC
```
